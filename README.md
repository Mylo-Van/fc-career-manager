# FC Career Manager
App Android para registrar tu carrera como DT en FC 25.

## Obtener el APK
1. Subí estos archivos a un repositorio de GitHub (rama `main`).
2. Entrá a la pestaña **Actions** y esperá que termine "Build APK" (~5 min).
3. Entrá a **Releases** (columna derecha del repo), abrí "latest" y descargá `FC-Career-Manager.apk`.
4. En el celular, abrí el APK y permití "instalar apps desconocidas".

Para cambiar la app, editá `www/index.html` y hacé commit: se recompila solo.
